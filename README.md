# Generador de Bloques Informativos para Moodle

Esta aplicación es un **Generador de Bloques Informativos para Moodle**, diseñado específicamente para facilitar el trabajo de la **Coordinación TDE (Transformación Digital Educativa)** o de los departamentos de informática en centros educativos.

Su objetivo principal es permitirte crear paneles visuales, modernos y muy organizados para incrustarlos en tu curso de Moodle **sin necesidad de saber programar** ni escribir código HTML a mano.

---

## 📌 ¿Para qué sirve cada sección?

La aplicación está dividida en cuatro pestañas principales:

### ⚙️ Configuración
Aquí defines los colores principales de los avisos y los datos de tu firma (tu nombre, departamento, instituto). También es donde puedes **guardar (exportar)** todo tu trabajo en un archivo `.json` o **recuperarlo (importar)** para no perder la información si cambias de ordenador.

### 👥 Coordinación TDE
Sirve para publicar las tareas que tienen que hacer los profesores, las fechas límite y listas de enlaces útiles (documentación, normativas, manuales…).

### ⚠️ Incidencias
Está pensada para mantener informado al claustro sobre el estado del soporte técnico. Puedes poner avisos (ej. *“usad el formulario”*), listar qué cosas se han arreglado esta semana y qué cosas están pendientes de solucionar.

### 📖 Buenas prácticas
Un espacio para poner normas de uso de las aulas, consejos de seguridad (como apagar las pizarras o cuidado con los pendrives) y trucos rápidos.

---

## 🚀 ¿Cómo funciona?

1. **Rellenas los datos**  
   Vas navegando por las pestañas y escribiendo los textos, fechas y enlaces en los formularios. La aplicación te va mostrando una **vista previa en tiempo real** a la derecha para que veas cómo va quedando.

2. **Generas el código**  
   Cuando tienes todo listo, pulsas el botón azul **"Bloque de Moodle"** (arriba a la derecha).

3. **Lo llevas a Moodle**  
   La app te genera automáticamente un código HTML perfecto, con estilos y adaptable a móviles. Solo tienes que darle a **"Copiar HTML"** y pegarlo dentro de un bloque HTML en tu Moodle (activando el modo código `< >` en el editor de Moodle).

---

## ✅ En resumen

Es una herramienta que convierte formularios sencillos en un diseño web profesional para que puedas **comunicarte de forma clara y atractiva** con tus compañeros docentes a través de Moodle.
